# SocietyConnect Analytics Upgrade

This build upgrades President Analytics with:

- Period selector: last 3 months, 6 months, 12 months, this year, custom range
- Category and block filters
- Period-over-period complaint count comparison
- Correct monthly complaint aggregation from real complaint dates
- Clickable monthly bars
- Status-stacked monthly bars (Resolved / In Progress / Under Review)
- Hover tooltips on bars
- Average monthly volume reference line
- Peak-month highlight and summary
- Click-through from chart/category/block insight to the complaints queue
- URL-aware complaint filtering for month/category/block/priority/assignment
- Unassigned filter support in President Complaints
- Dynamic weekday and operational analytics based on the active filter view

Run:

```bash
npm install
npm run dev
```
